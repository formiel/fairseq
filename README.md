This repo is a fork of fairseq. In addition to fairseq's features, it contains the code for the following work:
- Dual-decoder Transformer for Joint Automatic Speech Recognition and Multilingual Speech Translation (**COLING 2020, Oral**)
- Lightweight Adapter Tuning for Multilingual Speech Translation (**ACL 2021**)
- Pre-training for Speech Translation: CTC Meets Optimal Transport (**ICML 2023, Oral**)
